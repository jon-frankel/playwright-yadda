Reports what Yadda would throw about a Markdown feature: a scenario without steps, an examples row with a different number of fields than its heading, @a @b on one line, a table in a feature's description, and the other things its Markdown parser refuses.

The check is a port of Yadda's own Markdown parser, so it flags the same line, with Yadda's message, that playwright-yadda would fail on when it loads the file.
